### ⚠ BREAKING CHANGES

* `otel-html convert`, `serve`, `run` and `merge`, and `Report.create`, `convert` and `merge` in the library, now append to an existing report at the output folder instead of replacing it. Pass `--replace` (`replace: true`) to start the report over. `--append` (`append: true`) keeps its meaning of "a report must already be there". A report written by another otel-html version fails with a message naming `--replace` and `merge`; nothing is deleted.
